\# Library Management API



A REST API built with ASP.NET Core (.NET 10) for managing a library system.



\## Tech Stack

\- ASP.NET Core Web API (.NET 10)

\- C#

\- Scalar API Documentation

\- Repository + Service Pattern



\## Endpoints

\- GET /api/books

\- POST /api/books

\- GET /api/books/{id}

\- PUT /api/books/{id}

\- DELETE /api/books/{id}



\## Run locally

dotnet run
